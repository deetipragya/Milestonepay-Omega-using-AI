# 🛡️ EscrowGuard: E-commerce Website Delivery & Assurance Portal
An interactive, cryptographically verified milestone delivery and escrow verification dashboard for the **E-commerce Website Redesign** project. Built with pure HTML5, CSS3, and vanilla JavaScript for lightning-fast loading and zero-configuration hosting on **GitHub Pages**.
---
## 🌟 Key Features
- **📊 Executive KPI Dashboard**: Real-time breakdown of Base Budget (₹1,00,000), Contingency (₹10,000), Escrow Locked (₹60,000), and Released Funds (₹40,000).
- **🚩 Milestone Verification Ledger**: Detailed status tracking for M1 (Released), M2 (Blocked by QA Timeout), and M3 (Locked), complete with client reviewer sign-off details (`Sarah Jenkins`).
- **🔍 Requirements Traceability Matrix**: Searchable & filterable table of functional requirements (`REQ-01` to `REQ-04`) with linked pull requests and commit hashes.
- **🧪 Automated CI/CD Test Pipeline**: Test runner status for Unit, Integration, and Regression tests with an interactive modal log inspector.
- **📝 Scope Change Proposals**: Track cost and timeline alterations (`CR-01`, `CR-02`) with interactive simulated approval/rejection workflows.
- **🔒 Tamper-Resistant Audit Trail**: Live timestamped stream of all contract releases, test failures, and scope submissions.
- **⚡ Interactive QA Simulation**: Test the resolver workflow with one click using the **"Simulate QA Fix"** button to fix the Stripe gateway timeout, pass tests, and unlock escrow disbursement!
